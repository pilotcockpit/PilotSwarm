# Flight Deck sessions navigation: working notes (archived)

Point-in-time working notes from 1 November 2026. **Superseded by the design record,
[Flight Deck: Projects and Sessions Navigation](../../proposals-impl/flightdeck-sessions-navigation.md);** read that
first. These files are kept as history and are not maintained: they still say "folder" where the product now says
"Project", and several describe plans that were changed while building.

How they were produced, so nobody mistakes them for outside research:

- `00` is a read-only audit of backend code (nothing was run).
- `01` to `03` are memos written by an AI assistant in the roles of a product designer, a UX researcher and an
  information architect. They are structured reasoning, not user research. No users were interviewed.
- `04`, `05` are syntheses; `05a`, `05b` are two review rounds by a second AI model (Codex) with the changes it asked for.
- `06` is the design as it stood before building, with the owner's answers appended.

Every number in them (five rows, five folders, caps) is a hypothesis, not a measurement.
